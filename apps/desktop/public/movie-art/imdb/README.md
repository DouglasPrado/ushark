# IMDb artwork snapshots

Local, offline-ready snapshots collected on 2026-09-13 from the public IMDb
title pages listed below. Each poster is the page's `og:image`; each backdrop is
the first title-specific horizontal image presented in the title-page hero/video
area.

These files exist only to make the current UX prototype representative. IMDb's
non-commercial TSV datasets do not include artwork, and this repository does not
establish a production redistribution license for these images. Replace this
snapshot with an approved image provider/licensing contract before distribution.
