# M18 — sinal de sessão e matriz

O v1 considera TV somente quando o executável é iniciado explicitamente com
`--tv` pela entrada cadastrada no Sunshine; heurísticas de rede/foco não fingem
conexão. Política padrão é pausar. Shutdown tem budget de 5 s para helpers.
Matriz de aceite físico: Windows x64 + Sunshine/Moonlight suportados no dia do
teste + controle XInput; versões exatas devem ser registradas no checkpoint.
