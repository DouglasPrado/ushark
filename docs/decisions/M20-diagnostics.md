# M20 — diagnóstico v1

Coleta é local e sob demanda; nenhum envio remoto. Tokens, authorization,
cookies, magnets, paths, secrets e keys são removidos recursivamente. Logs têm
limite 1–1000 e retenção 1–365 dias. Zero medido permanece `0`; indisponível é
`null`. Limpeza é por categoria e não alcança biblioteca/preferências.
