# M12-D19 — precedência de apresentação

Decisão em 2026-09-14: dentro de uma biblioteca, `titleOverride` escopado ao
`libraryId` prevalece sobre metadata do catálogo, que prevalece sobre o ID como
fallback. Preferências, progresso, histórico e ocultações pessoais são estado
local do assinante e nunca entram no draft/export. Salvar permanece privado e
não publica nem inicia sources. O editor avançado é superfície desktop; TV é
somente consumo.
