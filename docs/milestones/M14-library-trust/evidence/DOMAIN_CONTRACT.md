# M14 S03 — contrato de domínio

Ed25519 assina libraryId/autor/schema/versão/SHA-256 canônicos. Verificação
criptográfica precede TOFU; primeira chave exige aceite, chave conhecida segue,
e troca nunca é aceita silenciosamente. Autenticidade não implica direitos.
