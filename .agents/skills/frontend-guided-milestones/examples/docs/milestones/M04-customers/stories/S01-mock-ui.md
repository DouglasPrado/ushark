# S01 — Customer Mock UI

## Objective
Criar as superfícies de clientes usando dados mockados atrás de um adapter substituível.

## Scope
- `/customers`
- `/customers/new`
- `/customers/:id`
- `/customers/:id/edit`

## Acceptance Criteria
- [ ] rotas navegáveis
- [ ] lista visualmente completa
- [ ] detalhes e formulários renderizam
- [ ] nenhuma dependência de backend real
