# Repository Agent Instructions

Este repositório usa **Frontend-Guided Milestone Development**.

## Fontes de verdade

Quando existirem:

- Produto: `docs/product/`
- Milestones: `docs/milestones/`
- Estado: `docs/execution/STATE.yaml`
- Política de execução: `docs/execution/GOAL.md`
- Decisões: `docs/decisions/`

## Regras persistentes

1. Antes de continuar uma implementação planejada, leia `GOAL.md` e `STATE.yaml`.
2. Execute uma story por vez e mantenha STATE/UPDATE sincronizados.
3. Milestones devem ser verticais e guiados pela experiência.
4. Não pule checkpoints humanos não aprovados, salvo instrução explícita do usuário.
5. Não avance para backend definitivo antes de o milestone ter experiência e contrato suficientes segundo o lifecycle definido.
6. Não marque milestone DONE antes de S08 Closure.
7. Para planejamento, execução, retomada ou auditoria de milestones, use `$frontend-guided-milestones` quando disponível.
8. Instruções explícitas do usuário prevalecem sobre estas convenções quando compatíveis com as permissões e políticas do ambiente.
